this program defines an Employee structure with an ID, name, and salary. It then performs several operations using STL algorithms:
Sorting: The employees are sorted by salary in descending order.
Copying: A subset of employees (those earning above a certain salary) is copied into another vector.
Accumulating: The total salary and average salary are calculated.
Finding the Maximum: The program finds the employee with the highest salary using max_element.
Each section prints details using the Employee_Details function.
